# Changelog

## [0.1.0-alpha.1] - 2026-08-14

### Added

- Browser-local Rust/WASM color conversion and CSS formatting.
- Bounded image palette extraction with transparent-pixel handling.
- Color harmony generation, WCAG contrast checks, color-vision preview, and CSS gradient output.
- Stable error codes for invalid colors, malformed pixel buffers, and resource limits.
- English-first documentation with a complete Chinese entry point.
