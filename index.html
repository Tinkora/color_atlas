Focused tools

A private, browser-first workflow for developers and designers.

Palette extraction

Extract dominant colors from a local image with bounded k-means sampling.

Color harmony

Generate complementary, analogous, triadic, tetradic, monochromatic, shade, and tint variants.

WCAG contrast

Compute contrast ratios and AA/AAA thresholds for normal and large text.

Vision preview

Review lightweight protanopia, deuteranopia, and tritanopia approximations.

CSS gradients

Build multi-stop linear gradients and copy the declaration.

Private by default

Color calculations run in browser WASM; images are not uploaded to a server.

Run locally

Use the Rust toolchain and wasm-pack to launch the editor locally.

1. Clone and build

# Clone the repository
git clone https://github.com/Tinkora/color_atlas.git
cd color_atlas

# Build the WebAssembly package
wasm-pack build --target web --release crates/color_atlas_web --out-dir static/pkg

2. Start the local server

cd crates/color_atlas_web/static
python3 -m http.server 8080

# Open http://localhost:8080 in a browser
